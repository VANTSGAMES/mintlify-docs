No necesitas desplegar todos los proyectos para empezar. Elige un componente, lee sus requisitos y realiza una comprobación local antes de configurar integraciones externas.

## Previsualiza este portal

Este recorrido permite consultar la copia guardada en Git sin configurar Discord, Cloudflare o bases de datos.

### Requisitos

- Acceso de lectura a `vantsgames/mintlify-docs`.
- Git, npm y Node.js 20.17.0 o superior, según los requisitos de la CLI de Mintlify.

<Steps>
  <Step title="Obtén el repositorio">
    ```bash
    git clone https://github.com/vantsgames/mintlify-docs.git
    cd mintlify-docs
    ```

    Los cambios que sigan como borradores del editor no aparecen en el clon hasta guardarse en Git.
  </Step>
  <Step title="Instala la CLI y abre la vista previa">
    ```bash
    npm install -g mint
    mint dev
    ```

    Abre `http://localhost:3000` y comprueba la navegación y una guía de repositorio.
  </Step>
  <Step title="Verifica tus cambios">
    Desde la misma raíz, ejecuta:

    ```bash
    mint validate
    mint broken-links
    ```

    Corrige los errores indicados antes de publicar. Estos comandos verifican documentación, no la ejecución de los proyectos descritos.
  </Step>
</Steps>

Consulta la [instalación de la CLI de Mintlify](https://mintlify.com/docs/cli/install) si necesitas resolver problemas de instalación.

## Antes de conectar servicios

- Usa credenciales y bases de datos de desarrollo.
- Comprueba las direcciones y organizaciones configuradas: algunos archivos conservan referencias antiguas.
- Distingue variables opcionales de requisitos del componente que vas a ejecutar.
- No interpretes una ruta de salud como verificación completa de todas las dependencias.
- Revisa los efectos de tareas programadas, migraciones y scripts de sincronización.

<Warning>
  Ejecutar un proyecto localmente no impide que consulte servicios externos. Los comandos de despliegue, el SQL remoto y las rutas de notificación pueden modificar sistemas reales. Empieza con los ejemplos de lectura de cada guía.
</Warning>
