## Alcance de las guías

Se documentan los ocho repositorios accesibles de la organización. Las guías se basan en los archivos y revisiones indicados en cada página, no en una comprobación de los despliegues activos.

<Note>
  Algunos README y configuraciones conservan nombres de organizaciones, rutas o tecnologías anteriores. Las guías señalan esas diferencias y priorizan el código revisado. Los comandos se ofrecen para tu entorno de desarrollo; no se ejecutaron servicios ni pruebas durante esta revisión.
</Note>
