[`vantsgames/docs`](https://github.com/vantsgames/docs) contiene un sitio mínimo de Mintlify llamado `vantsiap`. En el commit revisado, `235203c`, solo incluye `docs.json` e `index.mdx` como archivos del proyecto.

No contiene una aplicación backend, una API ni una configuración de despliegue de los servicios VANTS.

## Contenido actual

| Archivo | Contenido |
| --- | --- |
| `docs.json` | Tema `mint`, nombre `vantsiap`, color principal `#0D9373` y grupo `Home` con la página `index` |
| `index.mdx` | Página titulada `vantsiap`, con instrucciones genéricas de colaboración y edición en Mintlify |

La página inicial presenta edición mediante MCP, CLI, aplicación de escritorio y editor web. Es contenido de plantilla, no una especificación de las funciones de VANTS.

## Previsualizar el sitio

Necesitas acceso al repositorio, Git, npm y Node.js 20.17.0 o superior para la CLI de Mintlify.

```bash
git clone https://github.com/vantsgames/docs.git
cd docs
npm install -g mint
mint dev
```

Abre `http://localhost:3000`. La vista corresponde al contenido de este clon, no al portal de [mintlify-docs](/repos/mintlify-docs).

## Mantener el contenido

1. Edita `index.mdx` para sustituir la plantilla por el contenido que deba tener este sitio.
2. Conserva metadatos `title` y `description` en las páginas.
3. Si añades páginas, incorpora sus rutas sin extensión a `navigation` en `docs.json`.
4. Comprueba la documentación antes de publicar:

```bash
mint validate
mint broken-links
```

Consulta la [instalación de la CLI](https://mintlify.com/docs/cli/install) y la [referencia de páginas](https://mintlify.com/docs/organize/pages) para los requisitos de Mintlify.

## Diferencia respecto a mintlify-docs

| Repositorio | Alcance documentado |
| --- | --- |
| `vantsgames/docs` | Sitio mínimo `vantsiap` con una página genérica |
| `vantsgames/mintlify-docs` | Portal VANTSCC con las guías de los repositorios de la organización |

No se ha verificado un dominio o despliegue asociado a `vantsgames/docs`. Tener un archivo `docs.json` no identifica por sí solo dónde está publicado.

## Fuentes

`docs.json` e `index.mdx` del commit `235203c`. Los comandos de previsualización y validación proceden de la documentación de Mintlify. No se ejecutó una compilación ni se modificó este repositorio de origen.
